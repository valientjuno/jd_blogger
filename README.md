MY_FIRST_SITE
This website is a blog feature that share information and images about me outside of my software development interest.

## Key Features

Multi-page website structure with clear navigation (Home, About, Lifestyle, Foodstuff, etc.)
Custom layout and CSS styling for consistent design
Embedded images and organized content
Demonstrates understanding of HTML semantic structure

## Tech Stack

HTML: Structuring pages and content
CSS: Styling and layout

## Deployment - Use VS Code Go Live

Note: This site is not deployed online and is intended to be viewed locally by accessing the "Go Live" feature in VS Code.

git clone https://github.com/valientjuno/MY_FIRST_SITE
cd MY_FIRST_SITE

1. Open the project folder in VS Code.
2. Click the **Go Live** button at the bottom-right corner of the VS Code window.
3. Your default browser will open with the site running locally at `http://127.0.0.1:5500/`.
4. Any changes to HTML, CSS, or JS files will automatically refresh the page.
